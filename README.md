# Registro de Usuario - Unidad 4

## Descripción
Formulario con validación usando JavaScript y API nativa del navegador.

## Tecnologías
- HTML5
- CSS3
- JavaScript (ES6)

## Cómo ejecutar
1. Abrir index.html con Live Server
2. Probar el formulario

## Funcionalidades
- Validación por campo
- Validación en tiempo real (blur)
- Validación de contraseñas
- Mensajes de error personalizados
- Mensaje de éxito
